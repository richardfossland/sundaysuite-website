SundaySuite Norsk

Software for church and classroom

SundaySuite is a set of free programs for churches and schools, made in Norway. The source code is on GitHub. Questions, bug reports and requests go to dev@sundaysuite.app.

Download

SundayRec beta

Records the church service automatically on a schedule, and can stream it live and publish it as a podcast.

Download for MacDownload for Windows

The Mac version needs Apple Silicon (M1 or newer). More about SundayRec and installing it

In development

  • SundayScreen

    An offline classroom screen with a clock, countdown, name picker, groups and messages.

  • SundayStage

    Shows lyrics, Bible verses and images on the big screen in church.

  • SundayEdit

    Video captioning. Speech is transcribed automatically, and you correct what the program is unsure of.

  • SundaySync

    Syncs recordings from several cameras using their audio, and builds a timeline for DaVinci Resolve.

  • SundayStudio

    Podcast production with several microphones, editing and a finished MP3.

  • SundayTranslate

    Interpretation of the service straight to people's phones, and clearer sound for the hard of hearing.

Support

The programs are free. Running them still costs money: servers, domains and certificates for signing the apps. If you would like to help with that, you can send a Vipps payment to #24288 (Fossland Media). Vipps needs a Norwegian bank account; from abroad, write to dev@sundaysuite.app.

Fossland Media is the sole proprietorship behind SundaySuite. It is not a charity, so gifts are not tax-deductible.

Scan the code with your phone, or search for #24288 in Vipps.
