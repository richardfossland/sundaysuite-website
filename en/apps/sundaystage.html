SundayStage

Shows lyrics, Bible verses and images on the big screen in church.

In development. Not ready for regular use yet.

A program for Mac and Windows, in the same category as ProPresenter. You set up the order of the service in advance and run it from the keyboard.

What the congregation sees can be locked, so a wrong click does not end up on the screen. The program also keeps a log of the songs that were shown, with CCLI and TONO details, for reporting.

Want to try it anyway? There is an unfinished test build for Mac (Apple Silicon) and Windows. Expect bugs and missing pieces. Source code on GitHub
