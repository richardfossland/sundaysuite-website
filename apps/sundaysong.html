SundaySong

A song database built for Nordic rights reality.

Find the right song with semantic search and AI recommendations across languages — with TONO and CCLI built into the data model from the first row. Every song can carry a TONO id, and every use can record whether it was streamed (a separate royalty pool).

Keep me postedAll products
What it does

Search, suggest — with rights in the data model

The song catalog with rights identifiers as first-class data.

Semantic search

Search by feeling and theme, not just title — powered by vector search with pgvector.

AI recommendations

Get suggestions for songs that fit the text, theme and tone of the service.

TONO + CCLI

TONO and CCLI ids are first-class fields, so songs and uses carry the data a report would need.

Streaming flag

was_streamed separates in-room use from streamed use — a separate royalty pool.

Multilingual

Canonical songs with variants and translations linked across languages.

Open API

A public SDK lets the other Sunday apps look up and log songs.

The moat

Built for TONO from the first row in the database.

Most song tools are built around American CCLI. SundaySong has tono_work_id on every song and a streaming flag on every use from day one — that's the Nordic moat.

  • tono_work_id on every song from day one
  • was_streamed flag on every use
  • Designed for Norwegian-labelled TONO reports alongside CCLI

Status: in development

SundaySong is in early development. The data model and API contract with the TONO fields are in place, and the public SDK compiles against the contract; song import, search and AI are in progress. Not available for use yet.
